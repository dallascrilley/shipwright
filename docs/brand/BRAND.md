# Shipwright brand

**Mark:** Navy mallet forging a copper pull-request merge icon on an anvil  
**Vibe:** Craft, verification, trust-boundary shipping — forged, not guessed  
**Tagline:** Issues into tested PRs.

| Role | Color | Hex (approx) |
|------|--------|--------------|

| Copper (accent) | warm copper | `#C47B4A` |
| Cream | soft wash / splash | `#F5F0E6` |
| Spark / PR | brighter copper-orange | `#E08A45` |

## Naming

- Product name: **Shipwright**
- Pitch: An agent that turns approved GitHub issues into tested, reviewable pull requests.
- Emphasize craft + verify; the agent never holds GitHub credentials.

## Do / don't

- **Do** keep the PR/merge motif readable in the sparks.
- **Do** stay navy + copper (craft + heat of the forge).
- **Don't** go cute cartoon ship unless deliberately exploring a secondary mascot.
- **Don't** imply autonomous merge — Shipwright publishes only with human intent.
